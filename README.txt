NexService - Site institucional fictício | Projeto Integrador SENAI

Abra index.html no navegador ou use Live Server no VS Code.
Arquivos: index.html (Bootstrap e conteúdo), style.css (identidade visual), script.js (menu e aviso do formulário), img/ (logos originais do grupo).
Bootstrap e Bootstrap Icons são carregados por CDN; é necessária internet para esses recursos.
Os números, a história e as empresas parceiras são fictícios. O ADSync é o sistema principal do Projeto Integrador; NexMonitor e NexControl são projetos conceituais.
O formulário é demonstrativo e não envia dados.
